# Security Policy

NeuroTask is an academic portfolio project and is not intended to process real or sensitive information.

## Secrets

Never commit credentials, database files, production datasets, or a local `.env` file. Use `.env.example` only as a template.

## Reporting a vulnerability

Please contact the repository owner privately through the contact information on the [GitHub profile](https://github.com/StevenVegaL). Do not publish credentials or personal data in a public issue.
